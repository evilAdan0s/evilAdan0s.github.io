2025年终总结

2026-01-01 3 min read # 随笔

依然是31号晚上写年终总结，这已经成为了我跨年的一项必要仪式了，那么还是不废话，开始总结。

读书

今年稍微读多了一些，没有特别的偏好，想读什么就读什么。

  • 《认知驱动：做成一件对他人很有用的事》：有点像鸡汤书，但要高级很多，可以读
  • 《人体简史》：很好的科普书籍
  • 《仙症》 ：本来想自己描述下，但始终觉得不如书本身简介的一句话来的好——”世纪之交的北方城市里，人物始终处于失落之中“
  • 《生吞》：与上一本是同一个作者，悬疑小说
  • 《绝叫》：女性主义小说，可能要对日本社会比较了解才能体会到其中的内涵
  • 《最后的耍猴人》：很好的纪实文学，一个古老的职业是如何在现代社会中艰难爬行的
  • 《梅里雪山：寻找十七位友人》：这本是一次中日联合登山事故中幸存的日本登山队员写的，值得读
  • 《群星》：还不错的科幻小说，前期像悬疑恐怖，后期科幻内容差强人意吧
  • 《我与地坛》：之前一直没读过全集，读完之后很有共鸣
  • 《江湖丛谈》：讲真正的江湖行当、黑话和内幕的一本书
  • 《沉默》：与宗教有关的一本文学，很好读
  • 《南明史》：低血压必备，看完才能体会到当年那句”不复南明旧事“的内涵
  • 《当代中国政府与政治》 景跃进：这是一本教材，但我觉得每个爱键政的都应该看看，可以理解为这是执政党介绍自己行事逻辑的说明书，最好是第一版和第二版都看一遍

游戏

  • 刺客信条·幻景：还不错的新罐头，主线略短，20多个小时就通关了
  • 夺宝奇兵·古老之圈：还没打完，主要是解谜和演出，其中还有一章是关于中国淞沪抗战的
  • 羊蹄山之魂：也没打完，手柄摇杆漂移送去修了，这段时间非常沉迷，已经玩了快40个小时
  • 天国拯救2：仍然没打完，节奏慢
  • 星际拓荒：又又没打完，很好的太空探索解谜游戏
  • 赛博朋克2077：9月的时候打上mod又在PC端玩了近50个小时
  • 逃离鸭科夫：10月最喜欢的游戏

工作、学习与生活

今年最大的变化就是换了工作和城市，来到了上海。一开始有点不习惯孤独，毕竟跟上家公司的大家已经相处了三年多，即是同事也是朋友，后来慢慢也适应了，反而找到了一种平静。

学习的重心也改变了，去年的英语flag推进了一些，但还是不够。

5月因为出差又去了一次英国，这次是曼彻斯特，挺开心，明年想再去一次苏格兰。

另外，终于去看了许嵩的演唱会，呼吸之野济南场，也算圆梦了。

间歇性地开始运动，好歹动起来了，继续保持吧。

新的一年

不想再立flag，到时候在2026年终总结里找我都想干什么吧。
